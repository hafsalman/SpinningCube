# 🧊 Spinning Cube (Three.js)

This project demonstrates a **spinning 3D cube** using [Three.js](https://threejs.org/), a JavaScript library for rendering 3D graphics in the browser.

---

## 📌 What’s Included

- Scene, Camera, and Renderer setup  
- `BoxGeometry` and `MeshBasicMaterial`  
- Animation using `requestAnimationFrame`  
- Responsive canvas

---

## ⚙️ How To Run

1. Open Terminal on VS Code
2. git clone https://github.com/hafsalman/SpinningCube
3. cd Cube
4. Type "npm install three"
5. Type 'npm run dev' and press enter
6. Follow the link to see the spinning cube
